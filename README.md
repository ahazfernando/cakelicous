# Bloomly

Gifts and flowers — hand-tied bouquets, curated gift boxes, and same-day floral delivery.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
npm i
npm run dev
```

## Built with

- Next.js (App Router)
- TypeScript
- React
- Tailwind CSS
